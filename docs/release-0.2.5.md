The second independent review identified F024-1: the comparison indexed extended fields by ID, but excluded the `fields` key from the global comparison. Changes in its order or in whether the key was present could therefore disappear from the diff between two valid profiles. Candidate0.2.4 and its `revise` report remain unchanged, as do those of version0.2.3.

The detailed per-question comparison, evidence that IDs match, per-instance limits, and JSON type comparison corrected in0.2.4 remain in place. A reversed list, an absent key versus an empty list, or changed metadata are observable differences; a different order of keys in an otherwise unchanged object is not a change.
