# JSON Type Comparison, version 0.2.4

The independent review of candidate [0.2.3](release-0.2.3.md) identified F023-1: Python equality concealed changes between booleans and numbers, including within nested conditions and options. A modified valid form could have `changed=[]` and be considered ready for reuse. The candidate and the `revise` report are preserved; they are not replaced by this new delivery.

The fix covers complete JSON comparison, with regression checks for conditions, lists, extended fields, and metadata. Content that is genuinely unchanged remains unchanged. The validator code change requires new current snapshots: historical snapshots remain intact and are not rewritten. Before delivery, the relevant checks are repeated, new bytes are frozen, and another validator with no conversation history verifies the baseline and the fix.

There remain 29 skills and 29 local native definitions. Separate memory for each application and for the engine, freezing at gates, the maintenance process for the four guides and forms, and selection of dossiers to export are described in version 0.2.3. National provisions and Erasmus+ and ESC criteria remain separate. The active corpus is 2026; a new programme year is not promoted merely by changing a label.

To reproduce the corrected delivery, follow the [quick guide](quick-start-another-computer.md) and its `INSTALLA.md`, using the checksums in that package. The final report remains outside the ZIP so that it identifies the exact bytes reviewed. Local tests do not attest to another PC, new Codex discovery after restart, authentication, a complete regulatory refresh, signatures, or the quality of a real application.

The corrected integrated suite passes 299 tests. Local integrity checks for the 97 sources and the 29-skill/29-definition structure pass. The CLI comparison confirms 164 pages and 97 canonical sources are identical, and engine memory contains 8 records with explicit supersessions; the old hash for the replication guide is flagged in the history, with the original bytes preserved. The new delivery requires an external independent report tied to its hash.
