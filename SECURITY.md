# Security policy

Report suspected credential exposure, private-data inclusion, unsafe path handling, or integrity failures privately to the repository owner. Do not open a public issue containing the sensitive material.

This project assists human applicants. It does not submit applications, sign contracts, authenticate validators, or guarantee eligibility or funding. Current calls, forms, National Agency rules, deadlines, and corrigenda must be re-verified before use.

Supported releases are the tagged versions maintained in this private repository. Third-party source documents and tools retain their own terms and security lifecycle.
