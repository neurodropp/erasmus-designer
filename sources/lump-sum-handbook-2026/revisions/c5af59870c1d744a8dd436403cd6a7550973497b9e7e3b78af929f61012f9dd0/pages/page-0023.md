INDICATORS

Applicants for Cooperation Partnerships have to describe each work package (except WP1 –
project management) by defining specific objectives, targets, qualitative and quantitative
result indicators. This section provides methodological guidance for establishing a set of
indicators to support the assessment of project results.

What is an indicator?

An indicator is a measurable factor or value used to assess the quality of the project results
and thus, the level of achievement of the objectives. An indicator can be quantitative or
qualitative:
