# KA2 task file / Project Management Quality Plan

Read the [shared evidence contract](../erasmus-designer/references/evidence-contract.md), the **ka2-task-file** blueprint, and its `config/annexes.json` record. Consult the [template catalogue](../../wiki/templates/annex-template-catalog.md) only where relevant.

Materialise tasks, owners/contributors, milestones, effort, budget, status, evidence, and reporting from common registers. Treat historical TASK/DEOR workbooks as non-normative patterns only. Never duplicate master data or import partners, dates, or rates from examples. Trace every task to an activity, work package, and result, and reconcile all summaries.


Apply the [shared delivery contract](../erasmus-designer/references/annex-delivery-contract.md).
