# Detailed budget

Read the [shared evidence contract](../erasmus-designer/references/evidence-contract.md), the **budget-table** blueprint in [annex-blueprints](../../wiki/templates/annex-blueprints.md), and its `config/annexes.json` record. Use the [catalogue](../../wiki/templates/annex-template-catalog.md) only for sections relevant to the assignment.

Apply the financial model already verified in the common data. If it is missing or uncertain, return the decision to `erasmus-budget` before building the table. Separate estimated cost, grant allocation, and other resources; reconcile activity, work-package, partner, and overall totals. Apply the KA220 management cap to the total grant only where applicable; never transfer it to ESC or KA210. Do not reuse rates, broken formulas, or workbook caches as verified rules.


Apply the [shared delivery contract](../erasmus-designer/references/annex-delivery-contract.md) for common data, manifests, checks, and output format.
