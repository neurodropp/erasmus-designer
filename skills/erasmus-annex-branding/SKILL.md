# Branding and reusable document templates

Read the [shared evidence contract](../erasmus-designer/references/evidence-contract.md), the **branding-register** blueprint in [annex-blueprints](../../wiki/templates/annex-blueprints.md), and its `config/annexes.json` record. Use the [catalogue](../../wiki/templates/annex-template-catalog.md) only to locate sections relevant to the assignment.

Derive identity, accessibility, assets, versions, owners, formats, and channels from project needs. Verify current EU-funding acknowledgement rules; never invent mandatory logos or approved claims. Link each asset to project outputs and dissemination while recording sources and usage rights.


Apply the [shared delivery contract](../erasmus-designer/references/annex-delivery-contract.md) for common data, manifests, checks, and output format.
