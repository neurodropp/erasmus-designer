# Dispatch in a Fresh Session

The coordinator creates a new agent for every attempt at every phase using `collaboration.spawn_agent` and `fork_turns="none"`. Do not reuse a validator with `followup_task`, inherit chat history, or send leading conclusions. Producers may be reused for corrections, using exclusive paths.

Mandate template to complete with actual paths and identity:

> Read the erasmus-stage-validator skill at the specified absolute path. Validate the specified phase against the frozen package at the specified absolute path; open the manifest, criteria, checklist, and evidence. The application has the program, year, action, sector, and round shown in the manifest: report any inconsistency. Check all criteria and connections to relevant dependent products. Do not modify the materials or contact third parties. Write only to the assigned report path, using the specified contract. Return accept, revise, or blocked with evidence and localized discrepancies. Do not assume the materials are approved or accept their authors' judgments.

Record the tool response with the agent's real ID before acceptance. The final report must refer to the received manifest. An essential clarification is added to the package and triggers a new attempt with a new agent; do not give the old agent the desired conclusion to obtain approval.

With four total slots, complete the relevant production work and reserve one slot for the validator. During review, the orchestrator may arrange independent activities, but does not modify frozen files or start the dependent step. Reaching the revision budget produces blockers and the current version, not a false approval.
