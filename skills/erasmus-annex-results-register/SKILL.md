# Outputs, deliverables, translations, and releases

Read [the shared contract](../erasmus-designer/references/evidence-contract.md) and the **results-register** blueprint in [annex-blueprints](../../wiki/templates/annex-blueprints.md). Find the `results-register` record in `config/annexes.json` for columns, inputs, source refs, and checks. The [catalog](../../wiki/templates/annex-template-catalog.md) locates the original worksheets; read only the parts relevant to the mandate.

Link outputs, results, deliverables, and approved artefacts with versions, owners, languages, acceptance, status, evidence, and use/adoption. A produced file does not prove an outcome. Distinguish planned, delivered, and verified results; do not count language versions or formats as separate products without a definition.


Apply the [common delivery contract](../erasmus-designer/references/annex-delivery-contract.md) for shared data, manifest, checks, and output format.
